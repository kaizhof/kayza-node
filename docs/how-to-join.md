# 🌱 چگونه به کایزا بپیوندیم؟

## گام‌های ساده برای تبدیل شدن به یک گره سبز

### ۱. نصب متامسک
- افزونه **MetaMask** را برای مرورگر خود نصب کنید.
- [لینک دانلود](https://metamask.io/download/)

### ۲. ایجاد کیف پول
- یک کیف پول جدید بسازید یا کیف پول موجود را وارد کنید.
- **حتماً عبارت بازیابی (Seed Phrase) را در جای امن ذخیره کنید.**

### ۳. اتصال به شبکه پالیگان
- در متامسک، شبکه را به **Polygon Mainnet** تغییر دهید.
- اگر شبکه را ندارید، با کلیک روی "Add Network" آن را اضافه کنید:
    - **Network Name**: Polygon Mainnet
    - **RPC URL**: `https://polygon-rpc.com`
    - **Chain ID**: `137`
    - **Symbol**: `MATIC`

### ۴. باز کردن صفحه کایزا
- به لینک GitHub Pages خود بروید.
- روی دکمه **"اتصال متامسک"** کلیک کنید.

### ۵. شروع بازی
- در بخش **"باغچه من"**، یک دانه بکارید.
- هر روز آبیاری کنید و رشد گیاه خود را تماشا کنید.

### ۶. دریافت توکن
- با هر آبیاری، **توکن کایزا** دریافت می‌کنید.
- پس از رشد کامل، درخت را در طبیعت بکارید و پاداش بگیرید.

### ۷. کمک به خیریه
- در بخش خیریه، به **محک** یا **امام رضا (ع)** کمک کنید.
- تمام تراکنش‌ها روی بلاک‌چین ثبت می‌شوند.

---

## 🛠️ برای توسعه‌دهندگان
اگر می‌خواهید یک گره جدید راه‌اندازی کنید:
1. این مخزن را **فورک** کنید.
2. فایل `config.json` را ویرایش کنید.
3. GitHub Pages را فعال کنید.
4. لینک خود را به اشتراک بگذارید.
